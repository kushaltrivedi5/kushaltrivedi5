# Kushal Trivedi

**Co-Founder · Forward Deployed Engineer at [hussh](https://hussh.ai)** — Kirkland, WA

I build private, consent-first personal AI agents. At hussh we are building the infrastructure for a personal agent that lives in your own private compute, owns its memory, and acts only on explicit consent.

Before hussh: enterprise engineering at JioStar / Disney Star and Akasa Air. MS in Computer Science.

## What I'm building

- **Hussh One** — a personal agent (One) with specialist agents, on a consent-first runtime: one authoritative private agent per user, persistent memory inside the user's boundary, auditable and revocable data sharing.
- **Agent infrastructure** — MCP-based consent and tool access, A2A interoperability, private agent pods on GCP, and BYOC deployment paths where the customer owns the compute, credentials, and memory.
- **Break-testing as a discipline** — cold starts, revoked permissions, expired credentials, duplicate agents, recovery paths. Production and simulation stay strictly separated.
